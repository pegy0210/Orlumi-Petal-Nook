# @Orlumi Studio — @Petal Nook

## Project Type
Game Project

## Official Product Name
**Orlumi: Petal Nook**

## Studio Positioning
`@Orlumi Studio → @Petal Nook → Game Project`

Petal Nook is a game branch inside the wider Orlumi universe. It must remain visually, narratively, and commercially consistent with the Orlumi master brand rather than operating as a disconnected standalone title.

## Brand Anchor
**Little lights, little wonders.**

## Core Experience
A portrait-format cozy light idle / decor game centred on gentle progression, tiny treasures, soft surprises, collectibility, and quiet companionship.

## Core Character Anchor
**Lumie** — the main Orlumi character.

Lumie must retain:
- star-ears formed by the ear shape itself
- glowing droplet tail
- soft luminous eyes
- creamy white / pastel lavender / blush pink / pale gold palette

## Platform Direction
- Android first
- Portrait orientation
- Mobile touch controls

## Current Engine Status
- Existing prototype started in GDevelop
- Core logic completed through early implementation stages
- Current implementation checkpoint: Shop UI skeleton / Step 4
- Existing GDevelop work is retained as reference until engine direction is finalized

## Development Direction
The project may be implemented with a code-first engine such as Godot if this materially improves development speed, version control, testing, maintainability, and Android delivery. Migration must preserve finalized gameplay rules and approved art direction.

## Current v1 Scope
- Main room
- Little Pot interaction
- passive Petal income
- furniture purchase and upgrades
- Comfort progression
- Lumie first appearance
- Lumie movement and tap reactions
- annoyed state
- save/load
- offline rewards
- Shop
- Settings / reset
- Photo Mode
- future Area 2 reservation

## Art Direction
- dreamy
- soft
- gently glowing
- delicate
- collectible
- premium cute
- low-to-medium saturation
- warm pastel palette
- soft painterly 2D
- semi top-down / 3/4 spatial depth

Avoid:
- loud or cluttered UI
- cheap-looking bundled assets
- generic kawaii treatment
- overly childish presentation
- hard neon lighting
- unrelated visual styles

## Product Rule
Every feature, asset, character, environment, UI decision, monetization element, and future expansion must first feel like it belongs to Orlumi.
