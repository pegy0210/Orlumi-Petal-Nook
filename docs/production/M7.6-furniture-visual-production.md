## Layout baseline

MainRoom Layout A is locked:

- portrait mobile
- large central free-movement zone
- Lumie may roam broadly across valid floor space
- furniture develops at the room edges
- right side preserves future Area 2 geometry without showing a lock
- GDevelop HUD logic remains the UI baseline

## Universal furniture rule

All purchasable furniture starts at Lv0 = hidden. Lv1 is the first visible state. Lv1–Lv5 must remain recognisably the same object, same viewpoint and broadly the same footprint.

Visual progression now follows the owner-approved rule:

**add one cherished detail at a time → refine existing details → premium finish at Lv5**

Do not make levels look like unrelated replacement furniture.

## Wooden Rack — APPROVED DIRECTION A

Style:

- raw natural branch rack
- airy two-tier structure
- handmade, light and small-spirit scale
- restrained vines / bark detail

Progression:

- **Lv1:** rack + one relevant tiny treasure
- **Lv2:** add a second related treasure on the same shelf
- **Lv3:** add one related treasure on the other shelf
- **Lv4:** add one more related detail / small light charm
- **Lv5:** refine the full arrangement and rack finishing; richer but not crowded

Approved prop language:

- pressed-flower keepsake / card
- petal-shaped trinket dish
- tiny storybook / field journal
- pale-gold little-light charm
- tiny botanical keepsake

Avoid unrelated money bags, random jars, generic animal figurines or clutter.

Gameplay values stay unchanged:

- prices: 50 / 100 / 200 / 400 / 800
- income: 1 / 2 / 4 / 6 / 9
- Comfort: 4 / 8 / 13 / 18 / 24

Production source size remains `320 × 420` PNG.

## Curtain — APPROVED DIRECTION B: TWIN CURTAINS

Two-sided soft linen curtains are locked.

Progression:

- **Lv1:** twin plain curtains
- **Lv2:** add refined tie-backs
- **Lv3:** add one small windowsill treasure
- **Lv4:** add a second related detail / restrained hanging light detail
- **Lv5:** premium finishing, subtle trim and refined details without dense patterning

The Curtain remains a separate overlay and must not be baked into the base Opening BgRoom.

Production source size remains `360 × 260` PNG.

Gameplay values stay unchanged:

- prices: 120 / 240 / 480 / 960 / 1920
- income bonus: 5 / 10 / 15 / 22 / 30%
- Comfort: 6 / 12 / 19 / 26 / 34

## Small Table — APPROVED DIRECTION A: SINGLE-LEG ROUND TABLE

Structure:

- single central natural-wood pedestal / root-like leg
- round tabletop
- compact spirit-scale footprint
- Little Pot is placed on this table once the table is owned

Progression:

- **Lv1:** bare wood, no cloth
- **Lv2:** plain cream tablecloth covering the tabletop
- **Lv3:** add one small related treasure, kept away from the Little Pot centre slot
- **Lv4:** same one treasure + subtle floral cloth pattern
- **Lv5:** two small related treasures + more refined layered textile, e.g. shorter sheer layer or square topper

### Little Pot safety rule

Lv4 and Lv5 must preserve a stable central tabletop zone for Little Pot. Decorative objects may not sit at the extreme edge or collide visually with the pot.

Runtime behaviour is now defined so Little Pot moves from its floor slot onto the Small Table when `SmallTableLevel >= 1`.

Production source size remains `300 × 300` PNG.

Gameplay values stay unchanged:

- prices: 300 / 600 / 1200 / 2400 / 4800
- income bonus: 5 / 8 / 12 / 16 / 20%
- Comfort: 10 / 20 / 32 / 44 / 59

## Production acceptance

Before a final PNG enters the exact production path:

- correct source dimensions
- transparent background where the component requires it
- same object identity and viewpoint across Lv1–Lv5
- stable bottom-centre anchor
- no unrelated props
- no dense micro-patterns
- no furniture blocks the central Lumie movement corridor
- table Lv4/Lv5 visibly preserves the Little Pot slot
