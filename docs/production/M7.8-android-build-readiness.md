## Current artifact role

The debug APK is a production checkpoint, not a store release.

Its purpose is to validate that the same game project which passes headless CI can also be packaged into an installable Android binary before final visual replacement and release signing.

## Automated install-readiness gate

`tools/verify_apk_install_readiness.sh` performs static Android checks once an APK exists:

- APK exists and is non-empty
- Android signature verifies
- package id is `com.orlumi.petalnook`
- arm64-v8a native architecture is declared
- Godot Android native library is packaged
- metadata and APK contents are recorded for diagnosis

This gate supplements, but does not replace, real-device testing.
