## Locked progression principle

Furniture progression is no longer allowed to be five nearly identical images or five unrelated replacements.

Approved rule:

- keep the same core object / silhouette / viewpoint
- introduce one cherished detail at a time
- allow the room to visibly become richer with each level
- Lv5 refines the complete arrangement rather than simply adding clutter
